# Riverdirect

**DIRECT THE RIVER · 让安排顺着你的生活走。**

像素风日程与备忘工具，配有小河狸助手。手机随手输入一句，或在电脑按 **Ctrl+R**：接入你选择的 AI 后，小河可以理解事项、补充类别和详情，放入可视化日历；时间没定好时，先推荐空档，等你确认。零碎信息则收进备忘书架，需要时再问它。

## 从一句话，到看得见的安排

“明天找个时间跟 yvette 说一声测序的事。”

小河理解事项，结合已知日程推荐空档；你确认后，安排出现在日历对应位置。会议人、阅读程度等信息可填入类别专属字段；也支持继续对话修正刚刚的安排。复杂语义理解需要配置 AI，保存后请核对日期、类别和详情。

![一句话理解、推荐时间、确认后进入日历](images/01.png)

## 日程留在桌面，随时看一眼

电脑主窗口可切换为半透明桌面挂牌，查看今日与明日；也可开启小球或像素河狸悬浮待办，悬停查看、勾选完成。可设置关闭窗口后自动挂到桌面，以及开机启动后显示底层挂牌和置顶悬浮球。日历支持日、五天／七天和月视图，配有专注计时。

![应用日历切换为桌面挂牌](images/02.png)

## 给阅读安排一个位置

**可与 Zotero 联动**：搜索本机文献标题，选入日程，安排详读或略读。完成后可选写回阅读标签，默认关闭，需另行授权。NotePress 联动较有限，目前仅支持文献标题文件导入。

![Zotero 标题选入阅读周历](images/03.png)

## 类别由你定义，小河按你的方式陪伴

会议可以有参会人和会议方式，实验可以有实验类型与进度，阅读可以有书目和阅读程度。类别颜色、选择项、填写项都能自己设置。电脑端还能规划长期任务，再把步骤安排进日历。

电脑端修改使用中类别的颜色，已有日程会一起更新颜色，原有详情保留；归档日程保留历史颜色。选择类别或专注计时关联日程时，列表显示颜色小方块，便于查找。日历只在日程实际重叠的区间分栏。

日视图可展示日程详情；日、周、月视图均可导出为 3:4 竖版 PNG，适合保存或分享。内容较多时会自动续页。

小河的称呼、语气和长期偏好也由你决定。想回顾时，点击“小河想对你说”，生成总结；喜欢的内容可保存到时间手记。

## 碎信息收进书架，想找时问一句

“这个试剂放在细胞房的 −80℃ 冰箱。”——收进物品位置目录。

“试剂放在哪里了？”——查找已有备忘，不新增一条。采购清单、资料参数、个人偏好也有各自的位置；查询结果可贴成便签，最多保留三张。

## 下载与开始

| 设备 | 当前版本 | 使用方式 |
|---|---|---|
| Windows 10 / 11，64 位 | 0.1.26 | 下载 EXE，放入固定文件夹后双击，无需安装 Python |
| Android | 0.1.21 | 下载 APK 安装，主要用于查看、询问、上传与提醒 |

安卓包不是鸿蒙 6 原生应用。Windows EXE 约 83 MiB；APK 约 0.8 MB。版本号不同是两端独立迭代所致。

1. 可以先不登录，手动添加日程、体验日历和计时。
2. 需要 AI 时，在设置中填写服务商接口地址、模型和 API Key；每台设备单独填写 Key。
3. 需要同步时，两端用同一邮箱账号登录。普通试用者无需自建云端或执行 SQL。

## 使用前了解这些

- **本地副本＋临时中转同步**：电脑保存完整历史，手机可选 5／7／30 天缓存。修改经 Supabase 中转，接收成功后删除，未接收记录按 7 天期限过期并清理；账号与设备信息会保留。超过期限的补全需要持有完整副本的电脑在线。免费云服务可能休眠或限额，请保留本地备份。
- **AI 由你选择**：接口与模型设置可同步，API Key 不同步。使用 AI 时，输入及你允许参考的相关上下文会发往所选服务商，费用和数据处理规则由该服务商决定。
- **提醒有设备条件**：手机已缓存日程可使用本地通知，需要通知权限，效果受系统省电及后台限制影响。目前未接入远程云推送，不承诺电脑离线时立即收到其他设备新增的提醒。
- **Zotero 需设置**：标题搜索需要打开 Zotero 并启用本机 API；可选标签写回另需官方云端个人库读写授权与 Zotero 同步。并非安装后无需设置即可全部联动。
- **早期版本**：图中使用演示数据，包含流程示意；AI 示例不代表真实模型输出，也不代表所有手机上都已完成真机验证。使用前请备份重要安排，遇到问题欢迎反馈。
